# KiDE

**KiDE** — это легкая, быстрая и минималистичная среда разработки (IDE) для языков программирования C++ и Python. Программа написана на чистом C++ с использованием современной графической библиотеки **Nana C++**.

## 🚀 Основные возможности
- **Умная подсветка синтаксиса:** Разделение ключевых слов, типов данных и управляющих символов по цветам (синий, зеленый, кирпичный).
- **Многоязычность:** Автоматическое распознавание написанного кода. Запускает C++ через компилятор `g++` и Python через интерпретатор.
- **Работа с файлами:** Полноценное меню для открытия и сохранения файлов в форматах `.cpp`, `.py`, `.txt`.
- **Чистый GUI:** Графический интерфейс без лишних консольных окон при запуске самой IDE.
- **Встроенная иконка:** Программа имеет собственный значок в проводнике Windows и на панели задач.

## 🛠️ Требования для сборки из исходников
Если вы хотите скомпилировать проект самостоятельно, вам понадобятся:
1. Операционная система Windows.
2. Окружение **MSYS2** с установленным компилятором **GCC (g++)** в ветке **UCRT64**.
3. Установленная графическая библиотека **Nana C++** (`pacman -S mingw-w64-ucrt-x86_64-nana`).
